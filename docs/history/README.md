# How Glyphmotion was made

1. **The breach card.** A text-character animation of a humpback whale breaching at sunset, then a profile card with that scene running behind it (`examples/profile-card.html`).
2. **Component lab.** Four agents each built a sheet of web components in the style (`gallery/lab/`).
3. **Design language championship.** Four teams each built a full design language: logo, buttons, menus, cursor, hero, footer and a share moment (`round1-brief.md`). Six judges each scored one criterion with evidence (`round1-judging.md`, `judges/`). Final totals out of 60: Shoal 45.5, Meridian 40.5, Meltwork 39, Carrier 38.5.
4. **Mascot challenge.** Each team built a living mascot with at least seven emotions and pitched it (`round2-mascot-brief.md`, `gallery/mascots/`).
5. **The engine.** The shared core pulled out of all of the above into `src/glyphmotion.js`.

The briefs reference file paths from the original working folder, not this repository.
